# i18n (EN + FR)

- **No hard-coded user-facing strings** in components, alerts, accessibility labels, or navigation titles. Use `const { t } = useTranslation()` and `t('lighthouses.card.power')`. Outside React, use `i18n.t(...)` from `@/core/i18n`.
- Resources live in `src/core/i18n/locales/en.ts` (the source of truth) and `fr.ts` (typed `satisfies Translations`). Adding a key to `en.ts` makes TypeScript fail until `fr.ts` has it too. Always add both.
- Keys are namespaced by feature, then by screen or component: `lighthouses.detail.identify`, `settings.theme.title`, `common.actions.cancel`, `ble.errors.poweredOff`.
- Use interpolation for values (`t('lighthouses.count', { count })`) with i18next plural suffixes (`_one` / `_other`). Never concatenate strings.
- Protocol and technical identifiers (UUIDs, device ids, `LHB-xxxx` names) are not translated.
- French copy uses proper typography: accents, non-breaking spaces before `: ; ? !`, and « guillemets ».
